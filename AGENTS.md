# Project boundaries

This repository is a standalone synthetic experiment. Work only with its public
source and generated synthetic data. Do not read or connect to private projects,
conversations, voice assets, model checkpoints, services or credentials.

Keep the research question, measured results and limitations distinct. Delta-rule
associative memory is an established mechanism; do not claim it was invented here.
Do not describe a symbolic pairing score as natural-language memory, cognition or
general intelligence. Preserve reset, donor-state, dictionary and stale-link
controls when changing the experiment. Tests verify contracts; learned accuracy
belongs in a reproducible report rather than a unit-test success threshold.

Never overwrite a run. Publish no weights or private Git history. Any model run
uses random initialization, synthetic data and CPU; no external API is needed.
