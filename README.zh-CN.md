# Persistent State Lab：持续状态实验

**两段不同的过去，经历完全相同的近期输入后，能否仍让系统给出符合各自过去的答案？**

这是一个可以独立运行的小型数值记忆实验。先观察三组符号配对，经过
16 次相同干扰，再询问某个符号之前与谁配对。模型只保留一个 32 × 32
的数值状态，读取时不重新提供旧输入。

我们保留、清空、交换这份状态，并按照对应历史的正确答案评分。例如：

```text
过去 A：18 与 23 配对      过去 B：18 与 16 配对
           ↓                        ↓
       完全相同的近期输入和问题：“18 之前与谁配对？”
           ↓                        ↓
          23                       16
```

这里的研究取向是：经历应该能留下持续参与后续计算的内部条件。这个实验
具体检查早期内容的保留、选择和局部替换。它对应整个方向中的一段机制；
自然语境下的理解、选择性更新和完整修订还需要另外验证。

## 看到了什么

新复跑的两个固定随机种子，各评估 256 条未见过的配对序列：

- 保留状态：六个方向的原配对查询，各种子均为 **1,536 / 1,536**。
- 清空状态：三项查询只剩 **35 / 768** 和 **61 / 768** 正确。
- 交换状态：答案跟随另一段过去；按另一段过去评分均为 **768 / 768**。
- 替换一条正向关联后，新值能读回，其他两条关联保留。
- **具体失败：旧伙伴仍指向原来的符号，两种子各 256 / 256 条出现残留。**
- 保存完整历史的简单字典也能完成这道题；这里没有证明数值方案优于字典。

完整记录见 [results/reference.json](results/reference.json)，包括初始模型成绩、
训练曲线、对照和失败。样例固定取每个种子的前四条，没有按正确率筛选。

## 怎样复现

按 [英文 README](README.md#run-it) 建立 Python 环境，然后运行：

```bash
python -m unittest discover -s . -p 'test_*.py' -v
python experiment.py --output runs/my-first-run
```

默认从随机初始化训练两个模型，各 2,000 步；本次 CPU 复跑约 43 秒。
不需要 API key、预训练模型或外部数据。结果目录必须是新的，避免覆盖旧结果。
公开结果省略了可重新生成的稠密矩阵，保留全部评分、对照、曲线和样例；
完整报告及权重留在每次本地运行目录。用 `export_results.py` 可以生成相同格式。

## 怎么理解它的价值与边界

值得检验的是：过去留下的内容是否在后来被实际使用，以及我们怎样通过
干预定位它的作用。地址、值和写入强度通过训练形成，数值状态承担查询时
的内容保留；delta 更新本身是已有方法。

所有符号在训练时都见过，留出的是配对组合。配对边界由任务提供；干扰是
不包含原六个符号的单符号事件。当前没有证明开放语言理解、容量优势、
复杂干扰处理或完整关系撤回，成功成绩也不能代替这些问题的验证。
